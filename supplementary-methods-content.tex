\section*{Supplementary Methods}
Throughout this manuscript, sequence similarity is quantified using Average Nucleotide Identity (ANI), defined as:
\begin{equation}
    \text{ANI} = \frac{N_{\text{matches}}}{L_{\text{global alignment}}}
    \label{eq:ani}
\end{equation}
where $L_{\text{global alignment}}$ is the total length of the pairwise global alignment and $N_{\text{matches}}$ is the number of exact matches, counting only identical nucleotide pairs (A--A, C--C, G--G, T--T). Figure~\ref{fig:scaffolding-impact} (S3) and Figure~\ref{fig:mixture-resolution} (S2), both in the main text, use this definition of ANI to evaluate reconstruction accuracy.

\subsection*{S1. Evaluation of nf-core/viralmetagenome on public data}
A metagenomic dataset was constructed from publically available data by selecting a random subset of 2,000 records from the NCBI Virus database, targeting the following viruses: \textit{Orthonairovirus haemorrhagiae}, \textit{Mammarenavirus lassaense}, \textit{Zika virus}, \textit{West Nile virus}, \textit{Monkeypox virus}, \textit{Influenza A virus}, \textit{Severe acute respiratory syndrome coronavirus 2}, and \textit{Human respiratory syncytial virus A}. Records were filtered to retain only those with associated SRA data, sequenced on the Illumina platform, and with a LibraryStrategy other than `Amplicon'. From the resulting pool, 28 samples were randomly selected and downloaded using nf-core/fetchngs. Samples were then run with nf-core/viralmetagenome using default options with the exception of \texttt{--cluster\_method 'mmseqs-cluster'} due to sequence size limitations of cdhit, and \texttt{--skip\_read\_classification} to speed up the analysis.

For plant pathogens, two samples were randomly selected from the SRA at every query: \textit{Tobacco mosaic virus}, \textit{Tomato spotted wilt virus}, \textit{Cucumber mosaic virus}, and \textit{Potato virus Y}. These were also downloaded using nf-core/fetchngs and processed with viralmetagenome using the same parameters (\texttt{--cluster\_method 'mmseqs-cluster'}, \texttt{--skip\_read\_classification}), with the addition of the Virosaurus plant virus database as annotation database (\texttt{--annotation\_db} \url{https://ftp.expasy.org/databases/viralzone/2020_4/virosaurus98_plant-20200330.fas.gz}) and RVDB's v29.0 unclustered database as reference pool (\texttt{--reference\_pool} \url{https://rvdb.dbi.udel.edu/download/U-RVDBv29.0.fasta.gz}).

\subsection*{S2. Sample mixture resolution}
To evaluate the pipeline’s ability to distinguish viral genomes from the same species in mixed samples, we simulated a set of HIV-1 co-infections. We retrieved a random subset of 2,000 HIV-1 genomes (taxid: 11676) from NCBI Virus and selected MN090277.1 as the constant reference genome. We then calculated the pairwise Average Nucleotide Identity (ANI) between all 2,000 genomes and the constant reference genome (MN090277.1) using MMseqs2 \citep{Steinegger2017-ci}. Based on these ANI values, we binned the genomes into 0.5\% intervals (ranging from 74\% to 100\%) and selected one representative genome from each bin (n=38, Supplementary Table \ref{table:mixture}). Synthetic paired-end reads were generated for both the constant reference genome and the representative genome using InSilicoSeq v2.0.1\citep{Gourle2019-ox} in 'kde' mode with the 'MiSeq' error model. Mixtures were simulated at a 50:50 abundance ratio with 50x coverage for each genome.

The simulated mixtures were analyzed using viralmetagenome with the parameters \texttt{--skip\_preprocessing}, \texttt{--skip\_read\_classification}, and with U-RVDBv29.0 as a reference pool.

\subsection*{S3. Influence of scaffolding reference}
The choice of scaffolding reference can considerably influence the completeness of the reconstructed genome. To quantify this effect, we analysed a subset of 7 Lassa virus samples from our own sequencing efforts (Lassa virus - Illumina Miseq data with UMIs). We randomly selected samples based on their measured viral load during diagnostic testing, ensuring that the dataset encompassed different viral load categories (Supplementary Fig. \ref{fig:ct-distribution}). We compared consensus genomes generated using a gradient of scaffolding reference sequences ranging from 64\% to 100\% Average Nucleotide Identity (ANI) relative to the sample's baseline consensus.

To establish this gradient, we first generated a baseline consensus for each sample using the unclustered RVDB (U-RVDBv29.0) as the reference pool. We then retrieved all \textit{Mammarenavirus lassaense} (taxid: \texttt{3052310}) sequences from NCBI on the 24th of October 2025 (n = 2804) and calculated their ANI against these baseline consensus genomes using MMseqs2 \citep{Steinegger2017-ci}.  From this pool, we selected one scaffolding reference genome at every 2\% ANI interval for each sample (Supplementary Fig. \ref{fig:reference-selection}).  In total, we selected 157 reference sequences across the 7 samples (19--30 references per sample), spanning both L and S segments (Table~\ref{table:n_references} in the main text). The Lassa virus samples exhibited differential coverage between segments (S segment median ~231X, L segment median ~68X; Figure~\ref{fig:coverages} in the main text), allowing us to evaluate scaffolding performance on both complete and fragmented assemblies.

By default, nf-core/viralmetagenome selects the cluster centroid as a scaffolding reference. To assess the reference influence, we slightly modified the pipeline's code to force NCBI genomes as scaffolding reference. This version of the code repository is available in the release \url{https://github.com/Joon-Klaps/viralmetagenome/releases/tag/v1.0.0-force-external-centroid}.

We then ran the pipeline with the following non-default parameters: \texttt{--with\_umi}, \texttt{--umi\_deduplicate both}, \texttt{--skip\_read\_classification}, \texttt{--skip\_precluster}, \texttt{--intermediate\_consensus\_caller ivar}, \texttt{--consensus\_caller ivar}.

To quantify the impact of the scaffolding reference on the final output, we performed global alignments between each test consensus genome (generated with a forced scaffolding reference) and the corresponding baseline consensus genome (generated with automatic reference selection from U-RVDB) using MAFFT \citep{Katoh2002-ox} and determined their alignment statistics (number of exact matches, number of mismatches, and alignment length).

Figure~\ref{fig:scaffolding-impact}B shows only consensus genomes for which the supplied database reference genome sequence was included in the cluster and used as scaffold reference. During the clustering step (CD-HIT-EST with a default similarity threshold of 0.85 in this benchmark), CD-HIT-EST excludes supplied database reference genome sequences too divergent from the \textit{de novo} contigs from the cluster. In such cases, the pipeline proceeds without a database reference genome sequence, producing the same \textit{de novo}-only output regardless of which distant reference was supplied. Consequently, Figure~\ref{fig:scaffolding-impact}B contains fewer data points than the total number of selected references shown in Supplementary Fig.~\ref{fig:reference-selection}.

We observe an almost linear correlation between reference similarity and consensus accuracy for the L segment when database reference genomes were used for scaffolding (Figure~\ref{fig:scaffolding-impact}B; Figure~\ref{fig:coverages}A--B in the main text). For the S segment, this pattern is less apparent as \textit{de novo} assemblers could reconstruct near-complete genomes for most samples (Figure~\ref{fig:scaffolding-impact}B; Figure~\ref{fig:coverages}C--D in the main text). In the L segment, where coverage was lower, nf-core/viralmetagenome was particularly effective by connecting individual contigs to improve completeness, but the accuracy was dependent on the similarity of the scaffolding reference.
